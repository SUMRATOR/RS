## Как проверить архив

1. Скачайте `RS_V58_2026-11-26.zip` и распакуйте в любую папку.
2. Создайте окружение и установите зависимости:

   ```
   python -m venv .venv
   .venv\Scripts\activate          # Windows
   source .venv/bin/activate       # Linux / macOS
   pip install -e ".[dev]"
   ```

3. Запустите приложение:

   ```
   python -m rubik_studio
   ```

   Откроется окно или страница `http://127.0.0.1:8080`.
   Режим по умолчанию — desktop; серверный: `python -m rubik_studio --server`.

4. Прогоните проверки, которые выполняет CI:

   ```
   ruff check .
   pytest -q
   ```

   Ожидается: `All checks passed!` и **275 passed**.

## Что проверять в интерфейсе

**Темы — Настройки → Оформление:**

- четыре темы: Светлая (тёплая), Тёмная, Hacker, Своя тёмная;
- переключение применяется сразу, без перезагрузки;
- в «своей тёмной» задаются цвет подсветки и фон; слишком светлый фон
  затемняется автоматически — рядом показан расчёт контраста;
- проверьте, что темы меняют меню, карточки, таблицы, кнопки.

**Логотип:**

- виден в шапке на каждой странице, на главной и в «О программе»;
- на тёмных темах используется осветлённая версия, на светлой — исходная;
- если файл логотипа пропадёт, шапка не останется пустой.

**Нотация — редактор диаграмм:**

- панель «Символы» слева и колесо по клавише `V` работают одновременно;
- палитра событий: вкладки «Начальное / Промежуточное / Граничное /
  Конечное», внутри — карточки подтипов с кнопкой «добавить» и «подсказкой»;
- у граничных событий подписано, что они крепятся к границе задачи,
  и они нарисованы пунктиром;
- цвета символов нотации **не должны меняться** при смене темы: фон поля
  диаграммы во всех темах одинаковый.
