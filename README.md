## Как проверить архив

1. Скачайте `RS_V60_2026-11-28.zip` и распакуйте в любую папку.
2. Создайте окружение и установите зависимости:

   ```
   python -m venv .venv
   .venv\Scripts\activate          # Windows
   source .venv/bin/activate       # Linux / macOS
   pip install -e ".[dev]"
   ```

3. Запустите приложение:

   ```
   python -m rubik_studio
   ```

   Откроется окно или страница `http://127.0.0.1:8080`.
   Режим по умолчанию — desktop; серверный: `python -m rubik_studio --server`.

4. Прогоните проверки, которые выполняет CI:

   ```
   ruff check .
   pytest -q
   ```

   Ожидается: `All checks passed!` и **327 passed**.

## Что проверять в интерфейсе

**Главное: диаграммы должны открываться.** Если при открытии диаграммы
снова появится ошибка — пришлите текст из журнала, там будет точное
место.

**Значки-подсказки (новое):**

- «i» в полом круге — просто информация, наведите курсор;
- «?» в жёлтом треугольнике — возможная ошибка;
- «!» в красном круге — ошибка, в подсказке причина и где искать;
- работают наведение, клик и клавиатура (Tab).

**Страница «Диагностика»** (новый пункт меню) — сама проверяет базу,
права записи, логотип, данные и окружение. На исправной системе ошибок
быть не должно, только «i» и, возможно, «?».

**Карточка объекта:** вкладка «Атрибуты» должна прокручиваться целиком,
до последнего поля и кнопок.

**Меню:** «Моделирование», «Process Mining», «Задачи и процессы» больше
не дают 404, а открывают страницу «Раздел в разработке».

**Установщик:** см. раздел «Установщик» ниже — собирается на Windows.

**Темы, логотип, нотация** (из прошлых версий): четыре темы в
Настройках, логотип в шапке, цвета символов BPMN не меняются.

## Установщик

Установщик собирается на Windows в два шага:

```
python build_rubik_exe.py
python build_installer.py
```

Результат: `installer\RS_RUBIK_STUDIO_0.2.0_setup.exe`.

Для второго шага нужен Inno Setup 6 (бесплатный):
https://jrsoftware.org/isdl.php — если его нет, скрипт напишет об этом и
ничего не сломает.

Установщик не удаляет ваши данные: база, настройки и журналы лежат
отдельно, в `%LOCALAPPDATA%\RUBIK_STUDIO`, и остаются после удаления
программы.
