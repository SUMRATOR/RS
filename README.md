## Как проверить архив

1. Скачайте `RS_V59_2026-11-26.zip` и распакуйте в любую папку.
2. Создайте окружение и установите зависимости:

   ```
   python -m venv .venv
   .venv\Scripts\activate          # Windows
   source .venv/bin/activate       # Linux / macOS
   pip install -e ".[dev]"
   ```

3. Запустите приложение:

   ```
   python -m rubik_studio
   ```

   Откроется окно или страница `http://127.0.0.1:8080`.
   Режим по умолчанию — desktop; серверный: `python -m rubik_studio --server`.

4. Прогоните проверки, которые выполняет CI:

   ```
   ruff check .
   pytest -q
   ```

   Ожидается: `All checks passed!` и **298 passed**.

## Что проверять в интерфейсе

**Шапка и меню (новое в V59):**

- главная страница (`/`) теперь с шапкой, меню и переключателем темы —
  раньше это была отдельная страница без оформления;
- «Базы моделирования» — тоже с шапкой и меню, кнопки «На главную» больше нет.

**Объекты — карточка (главное изменение):**

- откройте «Репозиторий», создайте объект типа **Документ**, нажмите
  карандаш → вкладка «Атрибуты»: должны быть Номер, Дата документа, Статус,
  Автор, **Файл документа**, Действует до;
- создайте объект типа **Клиент**: поля ФИО, Дата рождения, Телефон, Почта,
  Тип клиента, Дата договора. Без ФИО карточка не сохранится;
- выпадающего списка «Тип значения» больше нет — вид значения подписан
  в подсказке у названия поля;
- «Добавить своё свойство» — для полей, которых нет в наборе.

**Нотация — редактор диаграмм:**

- стрелки должны начинаться на границе кружка/ромба, а не в пустоте рядом;
- потоки заметно толще технических связей; у сообщения открытая стрелка;
- вкладки «Начальное / Промежуточное / Граничное / Конечное» —
  выбранная подсвечивается, под ней меняются подтипы;
- группы палитры сворачиваются по клику на заголовок;
- символ можно **перетащить мышью** на поле диаграммы;
- полотно: пробел + перетаскивание двигает бесконечный лист под
  неподвижной панелью символов, колесо — масштаб.

**Темы — Настройки → Оформление (из V56, напоминание):**

- четыре темы: Светлая (тёплая), Тёмная, Hacker, Своя тёмная;
- цвета символов нотации при смене темы меняться не должны.
